# Trading Risk Assessment Dashboard

Інтерактивний дашборд для оцінки результативності, ризиків і потенційної життєздатності торгової стратегії клієнта CFD-брокера.

Дашборд допомагає швидко переглянути ключові показники: чистий P&L, Win Rate, Profit Factor, середній результат угоди, реалізовану просадку, використання Stop Loss / Take Profit, концентрацію експозиції та ознаки ризикової торгової поведінки, зокрема grid-підходу й averaging down.

## Відкрити дашборд

[Відкрити інтерактивний дашборд](https://volodymyrmoisieiev.github.io/trading-risk-dashboard/)

## Як запустити локально

1. Завантажте репозиторій як ZIP з GitHub.
2. Розпакуйте архів.
3. Відкрийте `index.html` у браузері.
4. Якщо пряме відкриття не працює, запустіть `python -m http.server 8000` з папки репозиторію та перейдіть на `http://localhost:8000/`.

Дашборд підготовлений як статичний HTML-звіт і не потребує доступу до вихідного датасету для перегляду.
